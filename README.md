# Lugia International

An illustration-led marketing agency website for Mohammed Dalvi. Off-white is the primary background, with selective beige accents.

## Preview locally

No package installation or build is required. With Python installed, run:

```sh
python -m http.server 4173 --directory dist
```

Open http://localhost:4173.

## Files

- `dist/index.html` — content and page structure
- `dist/style.css` — responsive styling
- `dist/app.js` — navigation and enquiry interactions
- `dist/assets/` — custom generated illustrations
- `ARTWORK.md` — artwork details and generation prompts
- `.openai/hosting.json` — existing Sites project configuration

Deploy `dist/` as a static website. The enquiry form opens an email draft in the visitor's email app; it does not send or store submissions on a server.
